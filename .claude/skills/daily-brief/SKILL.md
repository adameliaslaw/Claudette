# Daily Brief

Build Adam's morning briefing. Run the gathering steps in parallel.

## Gather

1. **Inbox** — search recent unread/important threads (Gmail, and Superhuman if linked;
   check `list_accounts` and cover every linked account). Classify: needs-reply-today /
   informational / can-wait.
2. **Calendar** — today's events in detail, rest of the week in summary
   (`Google_Calendar__list_events`). Flag anything court-related.
3. **Deadlines** — scan calendar events and inbox threads for dates within 14 days that
   look like filing deadlines, hearings, or response dates.
4. **Intake** — new Jotform submissions since yesterday, if any.

## Output format

- **Top 3** — the three things that most need Adam's attention today, one line each.
- **Today's Schedule** — times, participants, prep notes.
- **Needs Reply** — threads awaiting Adam, each with a one-line summary and a suggested
  disposition. Offer to draft replies (drafts only).
- **Deadline Radar** — anything due within 14 days.
- **New Intake** — new prospect submissions, one line each.
- **FYI** — everything else worth a glance, compressed.

## Rules

- Never send, archive, or delete anything during a brief — read-only, plus drafts on
  request.
- Keep the whole brief scannable in under a minute; detail goes behind follow-up asks.
